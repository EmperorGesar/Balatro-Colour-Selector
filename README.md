# Main Menu Theme Selector
A Balatro mod for choosing how your main menu looks: the background colours, the background theme of any installed mod, and the title logo.

*Formerly "Colour Selector". Fork of [EmperorGesar/Balatro-Colour-Selector](https://github.com/EmperorGesar/Balatro-Colour-Selector) - the original idea and version 1 are EmperorGesar's.*

## What it does
- **Your own colours always win.** Pick the outer and inner background colours yourself; they beat the main menu theme of any other mod (Lost Edition, ArtBox, Grab Bag, ...). Set a colour to **Auto** to use the theme again.
- **Background Theme:** every mod that paints the main menu background is detected automatically (no hard-coded list) and can be cycled through.
- **Title Logo:** every mod that ships its own Balatro title logo is detected automatically and can be cycled through.
- Everything sits in **ONE compact row** called **Main Menu Theme**, in `Options > Settings > Game`, under the Game Speed options. It opens a panel with all the controls, so nothing runs off screen.

## Install
1. Requires [Steamodded](https://github.com/Steamodded/smods) and Lovely.
2. Put the `Main-Menu-Theme-Selector` folder in `%AppData%\Balatro\Mods`.
3. Start the game and open `Options > Settings > Game > Main Menu Theme`.

## Upgrading from "Colour Selector"
Delete the old `Balatro-Colour-Selector` folder (and any inner `Colour Selector` folder) from your `Mods` folder before adding this one. Your old colour picks are not carried over.
